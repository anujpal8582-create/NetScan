A simple python-based network scanning tool designed for beginners who are learning networking and cybersecurity.

ABOUT PROJECT:
Netscan is a beginer-friendly python project created to explore basic network scanning concepts and understand how 
         network devices communicate.

FEATURES:
. Simple Python-based tool
. Beginner-friendly code
. Network scanning practice
. Useful for learning cybersecurity
     fundamentals.

REQUREMENTS:
. Python 3.x
. Windows / Linux
. Basic networking knowledge

INSTALLATION:
Clone this repository
git clone
https://github.com/anujpal8582-create/NetScan.git

Open the project folder:
cd netscan

RUN TOOL:
python NetScan.py
